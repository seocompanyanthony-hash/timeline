Timeline 中级 B班

Widget này dùng Scriptable để hiện tiết đang học, tiết tiếp theo và lịch hôm nay ngay trên màn hình chính. Nếu thấy trang lỗi có chữ data:text/html, đó là do mở nhầm trang preview; hãy copy lại mã widget bên dưới vào Scriptable.

Mở Timeline Tải mẫu Google Sheet

Cách cài

  1. Cài app Scriptable trên iPhone hoặc iPad.
  2. Mở Scriptable, tạo script mới tên Timeline B.
  3. Dán mã widget vào script đó, chạy thử một lần.
  4. Thêm widget Scriptable ra màn hình chính, chọn script Timeline B.

Sau này sửa lịch

  1. Mở file timeline-data.js trên máy Mac.
  2. Sửa phần schedule: 1 là Thứ 2, 2 là Thứ 3, tới 5 là Thứ 6.
  3. Đổi giờ bằng start/end, đổi tên môn bằng name, đổi giáo viên bằng teacher.
  4. Sửa ngày nghỉ hoặc ngày thi trong phần milestones.
  5. Hoặc dùng Google Sheet: import file google-sheet-template.csv, sửa lịch trên Sheet, publish dạng CSV rồi dán link vào googleSheetCsvUrl trong timeline-data.js.
  6. Reload app timeline. Widget sẽ lấy lịch mới khi server đang mở; nếu không thấy đổi, chạy lại script trong Scriptable hoặc xóa/thêm lại widget.
